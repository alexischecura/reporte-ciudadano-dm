# Reporte Ciudadano

Aplicación móvil para la Municipalidad de Gualeguaychú, diseñada para que los vecinos puedan reportar problemas en la vía pública de manera rápida y con geolocalización.

**Repositorio**: https://github.com/alexischecura/reporte-ciudadano-dm

## Características Principales

- Creación rápida de reportes (baches, luminarias, recolección, etc.) con foto obligatoria.
- Funcionamiento offline-first: los reportes se guardan localmente si no hay señal y se sincronizan al recuperar la conexión.
- Seguimiento de estados del reclamo y notificaciones para el vecino.
- Vista de mapa para identificar y adherirse a reportes cercanos, evitando duplicados.

## Stack Tecnológico

- **Framework:** React Native con Expo
- **Lenguaje:** TypeScript
- **Navegación:** Expo Router

## Cómo ejecutar el proyecto

1. Instalar dependencias: `npm install`
2. Iniciar el servidor de desarrollo: `npx expo start`
